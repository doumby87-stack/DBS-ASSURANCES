# Données de test

Jeux de données **entièrement fictifs** pour développer et tester l'application.

Règles :

- Jamais de vraies données clients ici, ni de copie de la base de production, même « anonymisée à la main ».
- Noms, numéros de téléphone (`+22507000000xx`), immatriculations et numéros de police inventés.
- Les fichiers seront ajoutés avec l'API (tâche 3 de la [feuille de route](../../docs/feuille-de-route.md)).

Les tests de `database/tests/` créent leurs propres données et n'ont pas besoin de ce dossier.
